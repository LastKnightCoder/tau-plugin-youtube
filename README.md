# YouTube

把 YouTube 上的课程、讲座加进 Tau，边看边记。视频会先缓存到本机，之后离线也能看；有字幕的视频打开就能跟着字幕读，划一句就能摘进笔记。

## 三步开始

1. **装好插件**：在插件中心安装「YouTube」，装好后直接启用，不用重启。
2. **添加视频**：在项目的「添加视频」、编辑器或白板里插入视频时选「YouTube」，粘贴视频链接。
3. **选清晰度**：解析完成后选一个清晰度，视频下载到本机后就能播放。所选清晰度不可用时，会自动改用能下载的最佳格式。

第一次解析视频时，Tau 会下载一个视频解析组件，这一步需要能访问 GitHub。

## 可以做什么

- **记视频笔记**：在项目里添加的视频会打开成左边看、右边记的视频笔记，可以插入时间戳、截取当前帧，详见 [视频笔记](https://taunote.app/docs/video-notes/)。
- **跟着字幕读**：视频自带字幕时直接显示，优先用人工字幕；没有字幕或对结果不满意，可以改用转录，把语音转成文字。
- **放进笔记和白板**：视频可以插进正文和白板，和其他内容放在一起。
- **作为学习资料**：在 Notebook 里添加视频资料，Tau 会把它转成文字，供 AI 检索和提问。

支持 youtube.com、youtu.be 和 yewtu.be 的视频链接。

## 打不开 YouTube 时

在插件详情的「设置」里，「网络连接」下的「代理地址」填上你的代理，例如 `http://127.0.0.1:7890` 或 `socks5://127.0.0.1:1080`，支持 HTTP、HTTPS 和 SOCKS5。留空表示直连。读取字幕也走这个代理。

## 常见问题

**在手机上能用吗？** 不能，YouTube 插件只在电脑上使用。

**解析一直失败怎么办？** 先确认浏览器能打开这个视频；打不开的话检查代理地址。第一次使用时还要能访问 GitHub，才能下载解析组件。
