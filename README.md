# YouTube

把 YouTube 视频加入 Tau：在编辑器、白板、项目的视频笔记或学习资料的「添加视频」中选择「YouTube」，粘贴视频链接，解析后选择清晰度即可添加。视频会先缓存到本地再播放，之后离线也能观看，并可用于转写与视频笔记。

支持 youtube.com、youtu.be 与 yewtu.be 的视频链接。所选清晰度不可用时自动改用最佳可用格式。

无法直接访问 YouTube 时，在「设置 · 账号与连接 · 在线视频」中填写代理地址，例如 `http://127.0.0.1:7890` 或 `socks5://127.0.0.1:1080`。首次解析时客户端会下载视频解析组件，需要能访问 GitHub。

从插件中心安装并启用。需要较新版本的 Tau 客户端。
