# YouTube

把 YouTube 上的課程、講座加進 Tau，邊看邊記。影片會先快取到本機，之後離線也能看；有字幕的影片開啟就能跟著字幕讀，選取一句就能摘錄進記事。

## 三步開始

1. **裝好外掛**：在外掛中心安裝「YouTube」，裝好後直接啟用，不用重新啟動。
2. **加入影片**：在專案的「加入影片」、編輯器或白板裡插入影片時選「YouTube」，貼上影片連結。
3. **選擇畫質**：解析完成後選擇一個畫質，影片下載到本機後就能播放。所選畫質不可用時，會自動改用能下載的最佳格式。

第一次解析影片時，Tau 會下載一個影片解析元件，這一步需要能連線到 GitHub。

## 可以做什麼

- **記影片筆記**：在專案裡加入的影片會開啟成左邊看、右邊記的影片筆記，可以插入時間戳、擷取目前畫面，詳見 [影片筆記](https://taunote.app/docs/video-notes/)。
- **跟著字幕讀**：影片自帶字幕時直接顯示，優先使用人工字幕；沒有字幕或對結果不滿意，可以改用轉錄，把語音轉成文字。
- **放進記事和白板**：影片可以插進內文和白板，和其他內容放在一起。
- **作為學習資料**：在 Notebook 裡加入影片資料，Tau 會把它轉成文字，供 AI 檢索和提問。

支援 youtube.com、youtu.be 和 yewtu.be 的影片連結。

## 打不開 YouTube 時

在外掛詳情的「設定」裡，「網路連線」下的「代理伺服器地址」填上你的代理，例如 `http://127.0.0.1:7890` 或 `socks5://127.0.0.1:1080`，支援 HTTP、HTTPS 和 SOCKS5。留空表示直連。讀取字幕也會走這個代理。

## 常見問題

**在手機上能用嗎？** 不能，YouTube 外掛只在電腦上使用。

**解析一直失敗怎麼辦？** 先確認瀏覽器能開啟這個影片；打不開的話檢查代理伺服器地址。第一次使用時還要能連線到 GitHub，才能下載解析元件。
